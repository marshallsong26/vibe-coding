# 카카오톡 공유 설정

오늘왜그래의 결과 카드 공유는 카카오 JavaScript SDK의 스크랩 공유를 사용한다. 각 동물의 전용 공유 페이지(`/share/{동물}`)에 설정된 제목, 꼬마동물 이미지와 설명을 카드로 만들며, 이미지와 카드 본문은 모두 해당 공유 페이지로 연결된다. 생년월일·출생시간·출생 도시와 아이의 애칭은 공유 페이지에 포함하지 않는다.

## 운영 설정

1. 카카오디벨로퍼스에서 애플리케이션을 만들거나 기존 앱을 선택한다.
2. **플랫폼 키 > JavaScript 키 > JavaScript SDK 도메인**에 `https://littlewhytoday.vercel.app`을 등록한다.
3. 이와 별도로 **제품 링크 관리 > 웹 도메인**에도 `https://littlewhytoday.vercel.app`을 등록하고 **기본 웹 도메인**으로 선택한다. 경로(`/share/...`)는 넣지 않는다.
4. 앱의 JavaScript 키를 Vercel 환경 변수 `NEXT_PUBLIC_KAKAO_JAVASCRIPT_KEY`로 등록한다.
5. 키를 새로 등록하거나 바꿨다면 Production 환경을 다시 배포한다. 제품 링크 설정만 바꾼 경우에는 재배포 없이 새 메시지를 공유해 확인한다.

이미 보낸 카카오톡 메시지는 이전 링크 설정을 유지하거나 카드 정보가 캐시될 수 있다. 설정 변경 후에는 결과 페이지에서 카카오톡 공유를 다시 실행해 새 메시지로 확인한다.

키가 없거나 SDK 초기화에 실패한 환경에서는 Web Share API를 열어 사용자가 카카오톡을 선택할 수 있게 하고, Web Share API도 없는 브라우저에서는 공유 문구와 링크를 복사한다.
